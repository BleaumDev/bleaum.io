Cash management

Set up registers, drawers and the vault, from the opening float to the end-of-day close.

Demo page with sample content

Point of sale

    Updated October 2026. About 5 minutes to read.

    Before you start. You need permission to manage cash settings, and at least one computer or tablet signed in to Bleaum at the counter.

    Add a register

    A register is one POS station. Add one for every checkout counter in the store.

    1. Go to Settings › Cash Management › Registers.
    2. Select Add register and give it a name your staff will recognize, like “Front counter”.
    3. Save. The register now appears in the list and on the POS sign-in screen.

    Add drawers to a register

    Each register can have one or more cash drawers. Track them separately so a count always matches one person's shift.

    1. Open the register you just created.
    2. Select Add drawer and name it.
    3. Enter the opening balance, the cash in the drawer when the shift starts.
    4. Test it: open the drawer, then close it, and check that both events appear in the log.
    Tip. Count the float twice before you type it in. Every end-of-day report compares against the opening balance.

    Set up the vault

    The vault holds cash that is not in a drawer: safe deposits, bank runs and change.

    1. Set the Main Vault starting balance.
    2. Log your first deposit so the vault history starts with a real entry.

    Close the day

    At the end of a shift, count each drawer and enter the total. Bleaum shows the difference from what the system expected, so you can review it before you close.
