# Website update tracker

Page-by-page change list for the Bleaum website rebrand (remove cannabis-specific wording, verify claims, fix technical issues). Split from `Bleaum_Website_Update_Sheet (1).xlsx` so each page can be updated in git.

## How to update

1. Open the page file below and work down its table.
2. Change the **Status** cell as you go: `To do`, `In progress`, `Done` or `Skipped`.
3. Add a line to **Notes** for any decision, approval or link to a PR.
4. New finding? Add a row at the bottom of the page file with the next free `#`. New page? Copy an existing file and add it to the index below.
5. Reviewed an item from [not-yet-reviewed.md](not-yet-reviewed.md)? Move its findings into the page file and set **Reviewed?** to `Yes`.
