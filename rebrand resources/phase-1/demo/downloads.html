Set up the Printer Client

Install it on one computer in the store. Tablets and other devices print through that computer.

  1. Install the client.It runs on Windows, macOS and Linux. Download it from the admin portal.
  2. Log in.Use your organization name, username and password.
  3. Choose an output type.Receipt, delivery receipt, pull sheet or product label.
  4. Assign a location and user.Printers are set per store and per user preference.
  5. Scan for printers.If yours is missing, select Rescan.
  6. Set up this device as a new client.Check the printer, then select the setup button.
  7. Run a test print.Check the printer and the alignment.

Change a template

  • Go to POS Settings › Print › Templates.
  • Pick a size: three defaults, or a custom size in mm.
  • Pick the label or receipt type.
  • Design from scratch in the builder.
  • Save, then assign it under Labels & Receipts › Config.

Troubleshooting

No printer found

Select Rescan in the Printer Client.

The print is misaligned

Adjust your template in Print Settings.

I need a custom size

Use the Template Builder.

Nothing prints

Check that the Printer Client is running on the host computer.
